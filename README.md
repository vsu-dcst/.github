# .github — public organization profile

This repository holds the **public profile page** of the
[Department of Computer Science and Technology](https://github.com/vsu-dcst), Faculty of
Computing, Visayas State University. GitHub renders
[`profile/README.md`](profile/README.md) on the organization's page at
<https://github.com/vsu-dcst>.

| Path | What it is |
| ---- | ---------- |
| `profile/README.md` | The public organization profile page |
| `assets/dcst-logomark-2025.png` | The DCST logomark, as adopted 22 January 2025 |

## Editing

Edit `profile/README.md` and open a pull request. Changes go live on the organization
page as soon as they are merged to `main`.

The department's vision, mission, goals, and objectives are quoted verbatim from the
minutes of the DCST emergency meeting of 22 January 2025. The faculty and staff
listings reflect the department's current roster and academic ranks; update both
whenever the roster changes.

Nothing confidential belongs in this repository — it is public, and so is its entire
history.

The member-only counterpart of this page lives in the private `.github-private`
repository.
